# Instalação correta no Windows

Se abrir uma janela com o logo grande do Electron e a mensagem `path-to-app`, isso significa que foi aberto o Electron puro e não o HostDeck instalado.

Use sempre:

`HostDeck-Setup-<versao>-x64.exe`

O instalador NSIS cria/recria o atalho `HostDeck` no Desktop e cria o atalho no Menu Iniciar. Ao finalizar, ele abre o aplicativo instalado.

Se você tinha fixado o ícone do modo de desenvolvimento, desafixe `Electron` da barra de tarefas. Depois de instalar, abra `HostDeck` pelo Menu Iniciar e fixe esse novo ícone.
